GAIC: Build a translator with QVAC
7 November 2026

MAIN PATH: TRANSLATION

1. Extract this folder and open it in your editor.
2. Open a terminal inside the folder.
3. Use Node.js 22.21.x. Check with: node --version
4. Keep internet on for software and model downloads.
5. Run: npm install
6. Run: npm run translate
7. Try your own sentence:
   npm run translate -- "The meeting starts at 6 pm."

The default sentence is: The meeting starts at 5 pm.
The program translates it from English to French.
The package pins @qvac/sdk 0.22.0. It uses BERGAMOT_EN_FR.
The model choice and the from/to settings must agree. Changing a language code does not add language support.

YOUR TASK
Run the example. Change the sentence. Keep the input and output.
Check names, dates, numbers and the main message.
Ask a fluent speaker to check important wording. If you cannot judge the French, write "quality not yet checked".

OPTIONAL: DOCUMENT SEARCH
Run: npm run search
Try another question:
   npm run search -- "Where is the training session?"

This downloads a separate GTE_LARGE_FP16 embedding model, about 670 MB for the main model file.
Do not start this download if it will prevent you finishing translation.
Edit the notes array in private-search.mjs to use 3 to 5 public or fictional notes.
Try a question with different wording from the notes.
The script prints matching passages. It does not generate an answer.
Similarity scores are not confidence percentages.
The built-in store is a prototype, used here for learning. The script removes its own temporary workspace when it ends.
